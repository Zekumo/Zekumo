hello-world.ts✧
// 和你的第一个小世界打个招呼 ✧
import Zekumo from 'zekumo-sdk';

const game = new Zekumo({
  appId: '你的 App ID',
  baseUrl: 'https://你的服务地址'
});

// 欢迎，一位新的冒险家！
await game.auth.loginAsGuest({
  deviceId: 'player-device-001'
});

// 把这一刻的成长，交给云朵保管
await game.playerData.set('save1', {
  level: 1, chapter: '旅途的开始'
});
# 1. 游客登录，获取 token
curl https://YOUR_HOST/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"app_id":"YOUR_APP_ID",
       "provider":"guest",
       "device_id":"player-device-001"}'

# 2. 用登录返回的 token 保存游戏进度
curl -X PUT \
  https://YOUR_HOST/v1/player/data/save1 \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"level":1,"chapter":"旅途的开始"}'

04 / BEFORE THE ADVENTURE

出发前的小问号。

和我们聊聊 ↗
什么样的游戏适合使用 Zekumo？＋

Zekumo 面向 H5、微信小游戏与独立小品游戏，提供玩家认证、存档、排行榜、运营与轻量实时互动能力。实时房间适合轻量状态同步；对复杂竞技游戏，仍需要根据玩法设计专门的权威游戏服务器。

可以部署在自己的服务器上吗？＋

可以。项目提供 Docker Compose 部署方案，后端使用 Go、PostgreSQL 和 Redis，产物存储支持本地磁盘或 S3 兼容服务。请按照仓库部署指南配置域名、密钥和数据库后上线。

有哪些客户端接入方式？＋

提供官方 JavaScript / TypeScript SDK 与 Go SDK，也可以通过 HTTP API 和 WebSocket 接入其他语言或引擎。微信等特殊运行环境需要适配其网络接口，具体请参考 SDK 文档。

这是托管云服务吗？如何开始使用？＋

这里介绍的是可自托管的开源后端项目。先按快速开始指南部署服务，再进入控制台创建游戏并获取 App ID；本页面不提供托管套餐或在线注册开通。
