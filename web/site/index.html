hello-world.ts✧
// Say hello to your first little world ✧
import Zekumo from 'zekumo-sdk';

const game = new Zekumo({
  appId: 'YOUR_APP_ID',
  baseUrl: 'https://YOUR_HOST'
});

// Welcome, a new adventurer!
await game.auth.loginAsGuest({
  deviceId: 'player-device-001'
});

// Keep your progress safe in the cloud
await game.playerData.set('save1', {
  level: 1, chapter: 'The journey begins'
});
# 1. Sign in as a guest to get a token
curl https://YOUR_HOST/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"app_id":"YOUR_APP_ID",
       "provider":"guest",
       "device_id":"player-device-001"}'

# 2. Save progress using the token returned by login
curl -X PUT \
  https://YOUR_HOST/v1/player/data/save1 \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"level":1,"chapter":"The journey begins"}'

04 / BEFORE THE ADVENTURE

Before you begin: a few questions.

Talk to us ↗
What kinds of games is Zekumo for?＋

Zekumo is designed for web games, WeChat mini games and small indie games. It provides authentication, saves, leaderboards, live operations and lightweight realtime interaction. Rooms support lightweight state sync; complex competitive games still need an authoritative game server designed for their gameplay.

Can I host it on my own server?＋

Yes. Zekumo includes a Docker Compose deployment setup and uses Go, PostgreSQL and Redis. Release artifacts can be stored locally or in S3-compatible storage. Follow the repository’s deployment guide to configure domains, secrets and the database before going live.

How can clients connect?＋

Official JavaScript / TypeScript and Go SDKs are available. Other languages and engines can use the HTTP API and WebSocket. Environments such as WeChat require adapters for their networking APIs; see the SDK documentation for details.

Is this a hosted cloud service? How do I get started?＋

Zekumo is an open-source backend you can host yourself. Deploy it using the quick-start guide, then create a game in the console to get an App ID. This website does not offer hosted plans or online service signup.
